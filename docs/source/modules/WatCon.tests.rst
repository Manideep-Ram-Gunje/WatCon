WatCon.tests package
====================

The test suite is not auto-documented module by module -- there are over forty
modules and their value is in what they assert, not in their API. Read them
directly in ``WatCon/tests/``; each carries a module docstring saying what it
covers and, where relevant, which defect it was written for.
